Panel polish and a guide

Task 022In progressfeat/ui-panel-polish

The list in the side panel now says what it is, the map's labels stay readable, loading and empty states are honest, and there is finally a user guide that explains every part of the screen.

How to see it

Read Using the app first: it explains the panel with a diagram. Then reload the app. The list has a heading, a one-line explanation, a count and a filter, and each row has a dot in the colour its kind has on the map. I have not looked at any of this in a browser yet.

What was built

  • A list that explains itself. "In this view" with a line saying it is everything inside the part of the map you are looking at. A count ("26 in view", or "12 of 26" when filtered) and a filter by kind. Rows imported from OpenStreetMap get a note about their titles.
  • Labels that stay readable. A point's label shows only when the camera is within 1,500 metres of it. The annotation you selected is always labelled. The distance is a first guess to tune by eye.
  • Honest loading. Grey placeholder rows while the first load runs, the empty message only after it finished, and "Loading the 3D viewer…" until the map is up.
  • Tidier panel. "New scene" is folded away once you have a scene. "Copy link" copies the address. The panel can be hidden and brought back. On a phone it sits at the bottom. The app icon sits next to the title.
  • A component copied from Sim UI. The badge with a coloured status dot, adapted so the dot takes the kind's map colour. Its licence notice is kept.
  • A user guide in the documentation site, linked from the README and from every page.

About Sim UI

Sim UI is a free, open-source, copy-paste collection of Angular components built on Spartan UI and Tailwind, under the MIT licence. Most of its examples are short compositions of Spartan's own components, so the polish comes largely from Spartan pieces we had not installed yet. The richer examples (accordion, tabs, dialog, select) need an icon package we do not have. That is a new dependency, so it is your decision, and it is listed in the spec as a candidate.
