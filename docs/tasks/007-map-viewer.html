The 3D map viewer

Task 007In progressfeat/map-viewer

A 3D map in the browser that loads only when needed, shows something useful with no setup, and cleans up after itself.

Try it

Start the client (cd client && npm start) and open http://localhost:4200. You get a globe centred on the Sagrada Família with a panel showing the camera position. This works with no account, using OpenStreetMap.

What is a Cesium ion token, and where do I get one?

To show real photorealistic 3D buildings the app streams data through Cesium ion, a hosted service. A token is a free key that tells ion which account is asking.

  1. Create a free account at ion.cesium.com.
  2. Open its access tokens page and copy the default token.
  3. In the app, open the Map panel, paste it into "Cesium ion token" and press Load 3D tiles.

It stays in your browser only. You can remove it with Forget token. Plans and limits are set by Cesium, so check their site. More in the glossary.

What was built

  • A map service that is the only code allowed to use Cesium. It exposes the camera position, the visible area and the map mode as signals, and releases everything when the page closes.
  • Loaded on demand. Cesium is about 5 MB. It sits in its own file and is fetched only when the viewer opens, so the first page stays light (259 kB at the time).
  • A graceful fallback. No token, or a rejected one, shows an OpenStreetMap globe and says so.
  • A debounced view. The visible area is published 250 ms after the camera stops, so later features do not query on every frame.
  • Spartan UI for the panel (button and input), with design tokens instead of hard-coded colours.

Data and terms

Photorealistic tiles are Google Photorealistic 3D Tiles streamed through Cesium ion and are subject to Google's and Cesium's terms. Cesium shows the required credits and they must stay visible. The OpenStreetMap fallback uses the public tile server, which does not allow heavy or production traffic, so it is for development only. The full notes are in the client README.

Known limits

  • Clamping annotations onto the 3D tiles uses Cesium's tile clamping, which was tested against a mock but not against the real tiles.
