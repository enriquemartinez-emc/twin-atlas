Finding annotations by area

Task 006Donefeat/annotation-reads

Everything the map needs to ask: what is in view, what is nearest to a point, and what is inside a zone, a page at a time.

Try it

# what is inside this view (west,south,east,north)
curl 'localhost:8080/api/scenes/SCENE_ID/annotations?bbox=2.17,41.40,2.18,41.41&limit=50'

# the 5 nearest to a point, with distances in metres
curl 'localhost:8080/api/scenes/SCENE_ID/annotations/nearest?longitude=2.175&latitude=41.405&limit=5'

Each page carries a nextCursor. Pass it back as cursor for the next page. The three endpoints are listed in the Swagger UI.

What was built

EndpointAnswersNotes
GET /api/scenes/{id}/annotationsThe list, or only what is visible when bbox is givenPaged with a cursor. A west value larger than east means the view crosses the date line.
GET .../annotations/nearestThe N closest to a pointOrdered by distance, with the distance in metres. Optional radius.
POST .../annotations/searchEverything that touches a zonePOST because the zone is a GeoJSON polygon. Paged like the list.

Why it works this way

Reads have no business rules, so they skip the pure rules and go straight from SQL to the response (ADR 0005). Native SQL is used because the spatial operators are not available in the object query language (ADR 0006). Paging by position stays fast and stable (ADR 0007).

How it was checked

CheckResult
Exact shape, not just its boxAn L-shaped outline is excluded from a view that sits in its empty corner, and included on its arm.
Date lineA view from 179 to -179 finds markers on both sides; 179 to 180 finds only one.
PagingWalking every page returns each row exactly once, in order, including when rows share the same timestamp.
Proof the tests can failRemoving the exact test, and then removing the id tie-break, each made the right test fail. Both were restored.
Index useOn 20 000 seeded rows the plans use the spatial index for the box query and the nearest query, and a time index for the list.
TimingEach query type records a timer visible through the metrics endpoint.
Whole backend at the time89 tests passing.

Known limits

  • The nearest query's radius pre-filter is a box in degrees that does not wrap the date line, so a radius search very close to it can miss matches. Acceptable for city-scale scenes and recorded in ADR 0006.
  • Speed at one million rows is not measured yet. That is task 009.
