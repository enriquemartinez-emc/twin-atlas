Scene page split

Task 025In progresschore/scene-state-split

The scene page was one 613-line component that did six jobs. Its state now lives in five small files, and the component only wires them to the map and the screen.

How to see it

Nothing looks different. Open client/src/app/features/scene/scene.ts: the class is 122 lines, and each part has its own file next to it.

What moved

FileWhat it holds
scene-workspace.tsWhich scene and annotation are chosen (from the address), the annotations in view, and how a choice goes into the address.
drawing-state.tsThe tool in hand, the points clicked, and saving something new.
edit-state.tsChanges to the chosen annotation that are not saved: a move, a refusal, a conflict.
scene-creation.tsCreating a scene that covers what the map shows.
link-copy.tsCopying the address and saying how it went.

Why functions and not services

The page's scene and annotation come from the address as inputs of the component. A service cannot read them, but a function that is handed the signals can. It is the pattern annotationData already used, so the page now has one way of doing this, and each function can be tested with plain signals and no browser or server.

How it was checked

CheckResult
BehaviourThe 44 page tests pass without any change to what they assert.
The moved logic21 new tests for the drawing state, the edit state and the link copy: a tool change clears the draft, an outline collects points, a move waits for a click, half-finished edits start afresh, a conflict is marked stale and another refusal is not, and the link label resets.
Deliberate breaksSix, each failed a test: an outline keeping one point, edits surviving a new choice, every refusal counted as a conflict, a move click selecting instead, a save staying in drawing mode, and the link label never resetting. One first break did not compile, so it was redone.
Build264 tests in all. Formatting, lint with the class check and the production build are clean.

Not verified

The app was not opened after the split. The page tests cover the behaviour, but nobody has clicked through it.

Left

The file is still 430 lines, because it holds the page's template and styles (about 300 lines). Pulling the side panel into its own component would shorten it, but it would need many inputs and outputs, so it was not done.
