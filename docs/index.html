Twin Atlas

A web app for exploring a real place in 3D, putting markers, notes and outlines on it, and finding things by area. These pages explain what has been built, one task at a time, in plain words with pictures.

The system on one page

Every box links to the task that built it. Colours mean the same thing on every page.

See it running

You need Docker, Java 25 and Node 24. From the repository folder, in three terminals:

docker compose up -d
cd server && ./mvnw spring-boot:run
cd client && npm start

Open http://localhost:4200, fly the map to a place, create a scene from the view, pick Marker, click the map, name it and save. The annotations task walks through it.
