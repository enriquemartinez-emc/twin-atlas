Twin Atlas documentation

Twin Atlas is a web app for exploring a real place in 3D, putting markers, notes and outlines on it, and finding things by area. This site explains what has been built, one task at a time, in plain words with pictures.

See it running in a few minutes

You need Docker, Java 25 and Node 24 on your machine. From the repository folder, in three terminals:

docker compose up -d
cd server && ./mvnw spring-boot:run
cd client && npm start

Then open http://localhost:4200. Fly the map to a place, create a scene from the view, pick Marker, click the map, give it a title and save. The annotations task walks through it.
