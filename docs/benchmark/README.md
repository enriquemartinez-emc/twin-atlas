# Benchmark results

Generated by `scripts/benchmark/run.sh` (about 3 minutes). Rerun it after changing a query or an index.

- [`results.md`](results.md): the machine, the data, API latency (p50, p95, p99) with and without the spatial index, and memory use.
- [`plans.txt`](plans.txt): `EXPLAIN (ANALYZE, BUFFERS)` of the four read queries with the GiST index and without it.

The seeded data is never committed, only the scripts in `scripts/benchmark/`. The decision record is [ADR 0009](../adr/0009-benchmark-one-million-rows.md), and [the docs page](../tasks/009-benchmark-dataset.html) explains it in plain words.
